The footer loads the LiveInternet counter requested for this site. The counter sends page and browser information to counter.yadro.ru, including the current page URL, referrer, screen dimensions, color depth and page title.

Game frames

Game iframes are click-to-load. Before you press Play, the external game client is not inserted into the page. After you press Play, the selected game provider receives the browser request and may use its own cookies, storage, account systems or measurement tools inside the embedded frame.
