Slope Keyboard Controls & Alternate Layouts

Use Arrow keys or A/D in the current standard control scheme. Miniplay also documents Q/A for left and E/D for right, which can be useful on alternate keyboard layouts.

⚡
Quick answer

Use the keyboard layout that the active Slope build actually supports. Arrow keys and A/D are widely documented; some hosted versions also show alternate letter bindings for different keyboard layouts.

Why alternate bindings exist

Letter positions vary across QWERTY, AZERTY and other layouts. A binding that is comfortable on one keyboard may be awkward on another, which is why some browser portals document more than one left-right pair.

Verify instead of assuming

The safest procedure is simple: click the game frame, test the left key once and then the right key once. If the ball or menu responds correctly, keep that pair for the session. Do not infer support from a guide if the current client behaves differently.

Consistency matters more than the specific pair

Switching between arrows and letters changes hand position and can change how long you hold a key. When practicing steering precision, choose one working pair so the input method stays constant while you compare decisions.

Browser focus still applies

A correct binding cannot work if the iframe is not focused. If the page scrolls or a browser shortcut fires, solve focus first. Then return to key mapping only if the frame is definitely receiving input.
