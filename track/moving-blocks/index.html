Moving Obstacles

When an obstacle changes position, the challenge is timing your arrival through a safe window rather than aiming at where the object is now.

⚡
Quick answer

Moving obstacles add timing to the normal clearance problem. Read the block’s direction, identify the space it is opening and plan a route that still has a safe exit if the timing shifts slightly.

Watch one movement cycle when space allows

If the obstacle is visible early, use that time to learn whether it slides, oscillates or changes the opening. Do not stare so long that the ball reaches the feature without a route decision.

Aim for space, not the obstacle

Track the open lane rather than visually locking onto the moving block. Your steering target is where the ball can safely pass, and that space may be easier to predict than the exact obstacle edge.

Leave timing margin

A route that works only if you arrive at one perfect instant is fragile. Prefer an opening with enough width and time that a small speed or line difference does not create an immediate collision.

Stabilize after the pass

Players often keep steering after the moving block is behind them. Release the correction and read the next platform; otherwise the successful dodge can create the next edge loss.

Apply Moving Obstacles in a normal run

Treat this page as a field test: make one prediction before the run, observe the result, then decide whether the cue deserves to stay. For Moving Obstacles, keep the first visible principle in mind: Watch one movement cycle when space allows. Then use aim for space, not the obstacle as the second checkpoint, so the test covers both the initial choice and what follows from it.

Repeat the test on several route shapes. The technique should adapt to gaps, turns, ramps or open track without becoming a rigid script. The cue is useful when it improves the decision while allowing the exact amount of steering to match the visible geometry.

Once the pattern is clear, stop over-analyzing it during every run. The purpose of practice is to make the cue simple enough that normal play can use it automatically while attention returns to the next visible part of the route.
